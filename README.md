# Pipeline_Derma

Pipeline de investigación y experimentación orientado a la clasificación de lesiones cutáneas mediante inteligencia artificial.  
Este repositorio reúne diferentes componentes para el trabajo con imágenes dermatológicas, incluyendo preparación de datos, organización de escenarios experimentales, integración de imágenes sintéticas, entrenamiento de modelos de visión por computadora y evaluación de resultados.

El objetivo del proyecto es servir como una base de trabajo para explorar enfoques de clasificación en dermatología computacional, especialmente en contextos donde el uso de datos sintéticos puede apoyar el análisis, el balanceo de clases y la experimentación con modelos.

## Alcance del proyecto

Este pipeline está enfocado en tareas como:

- Preparación y organización de datos dermatológicos
- Integración de imágenes reales y sintéticas
- Entrenamiento de clasificadores basados en visión por computadora
- Evaluación de distintos escenarios experimentales
- Análisis de resultados para investigación aplicada en inteligencia artificial

## Estructura general

El repositorio incluye componentes orientados a distintas etapas del flujo de trabajo, como clasificación, manejo de imágenes sintéticas, herramientas auxiliares y organización de escenarios de entrenamiento.

## Enfoque

Este proyecto forma parte de un trabajo de experimentación e investigación aplicado a problemas reales en el área de análisis de imágenes médicas y lesiones cutáneas, con interés en construir pipelines reproducibles y útiles para futuras mejoras, pruebas y validaciones.
